# 多报与漏报的成对决策学习

实验前固定：以容量对照的1.7B SFT adapter（开发集单故障8/8）为同一初始模型，比较决策字段SFT与决策字段SFT+DPO。数据仅来自原32旧+8新训练发布；显式模板规则重验标签，单故障候选负例多报一个根因，双故障候选负例漏报一个根因，共240个候选。它们是规则构造的错误集合，不伪装成真实模型犯错或人工偏好。

冻结初始模型按完整候选token的对数概率选择每个案例中概率最高的错误集合，记录全部候选分数、内容哈希和来源。公共前缀来自实际执行六类查询后的工具观察和固定提交字段头；标签只进入目标序列。两组均训练100步，学习率1e-5、种子42、4次单故障决策对1次双故障决策；SFT权重1，DPO分别为0或1、beta0.1。前缀和候选的拼接使用完整字符串token化后的公共边界。

该方法减少无关输出字段在训练中的占比，并直接约束过多/过少根因。两组都要重新自由生成完整工具交互；偏好对上的loss或排序正确率不算Agent任务成功。DPO多计算拒绝序列，故两组步数相同但FLOPs不相同。

先看原开发集，总准确率提高、单根因不低于各自初始模型且工具错误不增加才进入冻结测试。若DPO不优于同轮决策SFT，不将共同收益归因于DPO。通过开发门槛的候选在32条冻结测试上与初始模型配对评测一次，报告来源组bootstrap和分项退化；不以测试结果继续调参。
