# 模型容量与飞轮回训对照

2026-09-15，在本轮容量对照结果产生前固定方案。研究问题：同一训练机制下，更大的基础模型是否更能在学习双根因后保留单根因能力？不把不同基础模型的分数差当作飞轮收益。

比较本地Qwen3架构0.6B级checkpoint与下载的Qwen/Qwen3-1.7B，后者revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`。每个模型都先评测原始权重；用相同32条单根因示范训练120步（种子42、LoRA q/v rank16、学习率1e-4）；评测；再从各自SFT adapter在同一32旧+8新发布数据上训练100步（4:1回放、学习率2e-5、旧模型KL0.2、根因权重1）；再次评测。

训练与环境代码固定为 `15f8707`。入口是 `scripts/telelogs/run_capacity_control.sh`。每个模型单独占用一张空闲卡；至多2小时硬超时。步数与样本相同，但模型大小不同，因此不是等FLOPs比较。

主要报告：每个模型内部回训前后的总准确率、单根因保留、双根因准确率、集合F1与工具错误，再对比两个模型的变化。开发集仍为已检查12例。只有回训后总正确数提高、单根因不低于各自SFT、工具错误不增加，才对该模型的SFT与回训版本一起评测预先冻结32例；只运行一次，按来源组报告不确定性及分项退化。

如果均不通过，不扫描额外学习率或轮次，不解封测试，不采用新模型。若通过开发门槛但没有通过冻结测试，也不宣布净提升。该实验只检验简单合成环境，不提供官方TeleLogs成绩或实习业务证据。
