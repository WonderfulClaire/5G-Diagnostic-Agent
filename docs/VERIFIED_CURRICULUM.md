# 修复编号泄漏后的训练对照

2026-09-15，实验结果产生前固定。审查发现早期合成案例编号含标准根因ID，且模型提示词包含该编号；训练症状中的会话编号也与类别顺序相关。此前结果仅作旧协议调试证据，不再作为无标签泄漏的能力证据。

修复：模型输入完全移除案例编号，输出日志仍保留审计ID。提示词明确多种根因可共存，需逐一判断并列出所有有观测支持的原因。新训练数据使用与类别独立的吞吐和描述，同一组数值下覆盖单故障与双故障；每种诊断维度同时保留正常或异常观测，避免用整块替换隐藏正常信息。标准答案由独立数值规则复核，仅用于监督和环境评分，不进入模型提示。

训练：固定Qwen3-1.7B revision，种子42、q/v LoRA rank16、学习率1e-4、512步、原始全回答SFT。对照A为256条单故障，B为512条均衡单/双故障；两组总更新次数相同，回答长度和FLOPs不同。分别评测修复协议下的原始模型、旧SFT模型和两组新模型，不把提示词修复的收益归因于训练。

双故障训练组合固定成平衡环，每类出现两次，并排除已有开发集及预先冻结测试组合。旧开发集12例继续用于诊断；只有新模型优于同轮单故障对照，保住单故障能力并且工具错误不增加时，才将候选与同轮基线在32条冻结测试上配对评测一次。不得根据冻结测试继续选参数。

验收同时关注总/单/双故障Exact Match、集合F1、工具错误；后续还需跨种子及更有代表性数据。所有数据仍是可解释合成规则案例，不能视为真实网络故障验证。
